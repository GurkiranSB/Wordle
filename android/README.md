# Android app

This directory is the home for the native Android version of Wordle Assistant.
The Android Studio project and application source code will be added here as
implementation begins. The current Python command-line tool remains at the
repository root.

The planned app is a Kotlin app using Jetpack Compose, with a mobile-friendly
solver/coach interface and room for graphics and animations. The app should
ultimately use the same word list and solver behavior as the Python tool.
